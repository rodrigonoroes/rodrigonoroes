# Publishing the GitHub profile

GitHub displays a profile README when a public repository has exactly the same name as the user.
For this profile, the destination repository must be:

```text
rodrigonoroes/rodrigonoroes
```

## Publish manually

1. Create a public repository named `rodrigonoroes` without initializing it with files.
2. Copy `README.md` and the `assets/` directory from this folder into that repository.
3. Review the text and links before publishing.
4. Commit and push the files.
5. Pin `myfidelitycard` and the strongest representative repositories on the profile page.

Suggested commit message:

```text
docs: create BBS-style GitHub profile
```

Do not publish personal e-mail addresses, credentials, private project names or confidential
employment information in the profile.
